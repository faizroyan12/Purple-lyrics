CARA PAKAI
1. Buka folder ini di VS Code (File > Open Folder).
2. Edit config.js: tempel lirik, ubah caption, MODE, volume lagu.
   - Pisahkan kelompok lirik dengan baris kosong (5 kelompok = ikut BREAKS).
   - Atau pakai waktu manual: [00:12.5] liriknya
3. Jalankan index.html (klik kanan > Open with Live Server, atau buka di browser).
4. Klik "Klik untuk mulai" (browser butuh klik dulu supaya lagu bisa bunyi).
5. F11 untuk layar penuh, lalu screen recording. Klik layar / Spasi = ulang.
